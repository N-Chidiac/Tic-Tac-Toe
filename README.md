# Tic Tac Toe

A beautiful, responsive Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript.

## Features

-   Clean and modern UI with gradient backgrounds
-   Smooth animations and hover effects
-   Fully responsive design (works on desktop, tablet, and mobile)
-   Pop animations when placing X or O
-   Win and draw detection
-   Easy restart functionality

## How to Run

1. Download all three files: `index.html`, `style.css`, and `index.js`
2. Place them in the same folder
3. Open `index.html` in your web browser
4. Start playing!

## File Structure

```
tic-tac-toe/
├── index.html    # Main HTML structure
├── style.css     # Styling and animations
└── index.js      # Game logic
```

## Technologies Used

-   HTML5
-   CSS3 (Grid, Flexbox, Animations)
-   Vanilla JavaScript

## Game Rules

-   Two players take turns placing X and O
-   First player to get three in a row (horizontal, vertical, or diagonal) wins
-   If all cells are filled with no winner, it's a draw
-   Click "Restart Game" to play again

Enjoy the game! 🎮
